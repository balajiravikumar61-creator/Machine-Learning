Data Preprocessing & Invalid Zero Handling

Fig. 2 — Data Preprocessing

In the Pima dataset, zero values in clinical measurement columns (Glucose, Blood Pressure, Skin Thickness, Insulin, and BMI) represent missing or unrecorded tests rather than physiological values. We replace these with NaN and apply median imputation while carefully preserving valid zeros such as Pregnancies = 0.

{% for col, info in dataset.zero_invalid_summary.items() %} {% endfor %}
Feature Name Detected Invalid Zeros Missing Percentage Cleaned Imputation Median Handling Strategy
{{ col }} {{ info.count }} records {{ info.percentage }}% {{ info.median_excluding_zeros }} Median Imputer (Scikit-Learn)
Pregnancies Valid zero (0 = never pregnant) 0.0% 0.0 Preserved Unaltered
Preprocessing & Scaling Pipeline Architecture:

1. SimpleImputer(strategy='median') → 2. StandardScaler() (zero mean, unit variance) → 3. Classifier. Encapsulated into a single Scikit-Learn Pipeline so both training and live prediction process invalid zeros and standardization identically.
